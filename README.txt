AURENIX PREMIUM STORE
DEPLOY: publish the repository with GitHub Pages.
EDIT PRODUCTS: edit the products array inside index.html (name, cat, price, img, desc).
PAYMENTS: run supabase-schema.sql in Supabase SQL Editor, then configure the server environment variables in Vercel.
REQUIRED SERVER VARIABLES: RAZORPAY_KEY_ID, RAZORPAY_KEY_SECRET, SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY.
OPTIONAL AUTOMATION VARIABLES: N8N_WEBHOOK_URL, N8N_WEBHOOK_SECRET.
Razorpay INR is the default checkout currency. USD requires international payments to be enabled in Razorpay and a documented exchange-rate policy.
SUPPLIERS: verify stock, shipping time, tracking, return policy, product quality and permission to use images/descriptions. Printful supports ecommerce integrations and API/manual-order workflows; custom stores need an API connection for automatic fulfillment.
IMPORTANT: sample reviews and product data are placeholders. Publish only genuine reviews and real claims.

BRAND UPDATE: Supplied AURENIX logo is included as aurenix-logo.png and used in the header. The new editorial sections are original and inspired by the clean conversion-focused feel of the reference, not copied from it.
